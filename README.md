### Adding a New Day

```bash
just new-day 2
```

This creates `src/day2.rs` with a template, `src/inputs/input-day2.txt`, and updates `Cargo.toml`.

### Running Solutions

```bash
just run 1       # Run day 1
just run-opt 1   # Run day 1 (release mode)
```
